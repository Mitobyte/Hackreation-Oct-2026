## Role 1: Manual Test Runner

Runs written test cases step by step on fitness-equipment consoles, marks each step pass or fail, and attaches a screenshot to every failure, so testers can spend their time writing tests and automation.

- **Hours:** 10-15 per week; weekday daytime in the test center
- **Pay:** same starting rate as the company's test technicians (not stated in posting)
- **Support intensity (of the role):** moderate
- **Frees up:** software testers who run regression checks by hand
- **Growth path:** add starting automated runs (j3); writing defect reports (j6) stays with testers

| Task | Standard (what done looks like) | Frequency |
| --- | --- | --- |
| Run written manual test cases step by step on the equipment console and mark each step pass or fail | every step marked pass or fail; any fail has a screenshot | daily |
| Attach a screenshot or short video to each failed step in the test log | every failed step has evidence attached | as fails occur |

**Executive-function demands (role level)**

| Dimension | Demand |
| --- | --- |
| working memory | medium |
| sequencing | medium |
| time management | low |
| attention | medium |
| organization | low |
| flexibility | low |
| social communication | none |
| sensory load | low |
| paperwork | medium |

**Supports the employer agrees to provide**

- test cases with one action per step and a picture of the expected screen
- pass/fail log template with a screenshot button
- quiet test bay or headphones where safe
- a named tester to hand failures to
- job coach for the first weeks; check-ins every 2 weeks

_Why these tasks belong together:_ both tasks happen at one console, in one test case at a time

**Variations of this role (tasks and schedules can be mixed)**

- **Core:** Label, charge, and tidy test units and cables in the test center — 2 h/day x 2 days = 4 h/week total (two weekdays) or 2 h/day x 3 days = 6 h/week total. Support intensity: light. Good fit: likes careful, repeatable work and wants to learn the test center first.
- **Standard:** Run written manual test cases step by step on the equipment console and mark each step pass or fail; Attach a screenshot or short video to each failed step in the test log — 3 h/day x 3 days = 9 h/week total or 5 h/day x 3 days = 15 h/week total. Support intensity: moderate. Good fit: comfortable following written steps exactly and noticing when a screen looks wrong.
- **Plus** = Standard + Start automated test runs from a checklist and save the result logs — 5 h/day x 3 days = 15 h/week total or 5 h/day x 4 days = 20 h/week total. Support intensity: moderate. Good fit: ready to start automated runs and save their logs. Extra supports: checklist for each automated suite.

_Schedules above 15 hours a week, and any schedule a specific client takes, go to an ERI benefits counselor first._

## Role 2: Test Center Setup Helper

Keeps test units labeled, charged, and loaded with the right build before each run, so testing starts on time.

- **Hours:** 10-15 per week; weekday mornings before the day's runs
- **Pay:** same starting rate as the company's test technicians (not stated in posting)
- **Support intensity (of the role):** moderate
- **Frees up:** testers who set up units before running tests
- **Growth path:** add running manual test cases (j4)

| Task | Standard (what done looks like) | Frequency |
| --- | --- | --- |
| Set up test units before each run: power on, load the build from the posted card, reset to factory state | unit shows the right build number and the home screen | before each run |
| Label, charge, and tidy test units and cables in the test center | every unit labeled and charging; cables coiled on hooks | start and end of shift |

**Executive-function demands (role level)**

| Dimension | Demand |
| --- | --- |
| working memory | medium |
| sequencing | medium |
| time management | low |
| attention | low |
| organization | low |
| flexibility | low |
| social communication | none |
| sensory load | low |
| paperwork | low |

**Supports the employer agrees to provide**

- laminated setup card at each unit, with photos of each screen
- build-number check box on the card
- fixed hooks and labels for every cable
- a named tester to ask

_Why these tasks belong together:_ both tasks prepare the same units in the same room

**Variations of this role (tasks and schedules can be mixed)**

- **Core:** Label, charge, and tidy test units and cables in the test center — 2 h/day x 2 days = 4 h/week total (two weekdays) or 2 h/day x 3 days = 6 h/week total. Support intensity: light. Good fit: prefers a hands-on, tidy routine in one room.
- **Standard** = Core + Set up test units before each run: power on, load the build from the posted card, reset to factory state — 3 h/day x 3 days = 9 h/week total or 5 h/day x 3 days = 15 h/week total. Support intensity: moderate. Good fit: comfortable following a setup card exactly.

_Schedules above 15 hours a week, and any schedule a specific client takes, go to an ERI benefits counselor first._
